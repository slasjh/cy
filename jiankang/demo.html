3D坦克大战

击败所有敌人和BOSS进入下一关！

游戏说明

使用 WASD 移动坦克，鼠标瞄准，点击左键射击

数字键 1-3 使用技能 (每关5次)

按 B 键打开背包查看物品

游戏规则

基本规则

1. 使用 WASD 键移动坦克

2. 使用鼠标瞄准，左键点击射击

3. 每个敌人需要击中3次才能消灭

4. 被击中5次游戏结束，但有一次复活机会

5. 利用地形躲避敌人攻击

技能系统

1. 每关可以使用5次技能

2. 手榴弹 (1): 范围伤害，对区域内敌人造成3点伤害

3. 护盾 (2): 5秒内免疫伤害

4. 闪电 (3): 直线伤害，对路径上的敌人造成2点伤害

物品系统

1. 消灭敌人有机会掉落物品

2. 医疗包: 恢复1点生命值

3. 武器: 随机获得霰弹枪或步枪

4. 技能点: 恢复1次技能使用次数

5. 不死图腾: 获得一次复活机会

BOSS战

1. 每关消灭所有敌人后BOSS会出现

2. BOSS有更高的生命值和更强的攻击

3. 击败BOSS获得稀有奖励

其他功能

1. 按 B 键打开背包查看物品

2. 每通过一关增加一点生命上限

3. 右上角有小地图显示位置
