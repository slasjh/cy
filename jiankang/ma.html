肾--综合调养手册

（66岁女性适用，注重护肾排毒、控制并发症）

一、简易中药调养法

原则：以温和补肾、利水排毒为主，避免峻猛攻伐之药

✅ 家庭适用方剂

  • 玉米须茶（日常代茶饮）
    • 材料：干玉米须15g（中药店可购）
    • 做法：沸水冲泡，代茶频饮
    • 功效：利水消肿，适合轻度水肿患者
  • 山药芡实粥（早餐）
    • 材料：山药50g（鲜品更佳）、芡实30g、粳米50g
    • 做法：所有材料慢火熬煮1小时
    • 功效：健脾补肾，适合消化功能较弱者
  • 黄芪枸杞泡水（上午饮用）
    • 材料：黄芪10g、枸杞15g
    • 做法：保温杯闷泡30分钟后饮用
    • 注意：感冒发热时停用
重要提示：所有中药使用需遵医嘱，出现以下情况立即停用：
  • 水肿加重
  • 尿量异常减少
  • 恶心呕吐
  • 心悸气短

二、居家运动建议

原则：以不疲劳为度，避免剧烈运动

✅ 推荐运动

  • 晨起养生操（5分钟）
    1. 干梳头：双手十指从前发际梳至后发际50次
    2. 摩腹：顺时针按摩腹部100圈
    3. 叩齿：上下牙齿轻叩36次
  • 散步（每日2次）
    • 时间：餐后1小时
    • 强度：以不喘为度，每次15-20分钟
  • 床上八段锦（睡前）
    • 重点练习"两手托天理三焦"和"调理脾胃须单举"
    • 每个动作重复3-5次

三、简易护肾食谱（一周示例）

时段 周一 周三 周五
早餐 山药芡实粥 + 水煮蛋 南瓜小米粥 + 蒸红薯 燕麦片（无糖） + 核桃2个
午餐 冬瓜肉丸汤（瘦肉50g） + 蒜蓉空心菜 + 红薯饭 番茄龙利鱼 + 凉拌黄瓜 + 玉米饭 白菜豆腐煲 + 胡萝卜炒木耳 + 荞麦面
加餐 苹果1个 无糖酸奶100g 雪梨1个
晚餐 芹菜百合 + 山药羹 冬瓜海带汤（少量海带） + 蒸南瓜 白菜粉丝煲 + 玉米糊

✅ 推荐食物清单

🥬 护肾蔬菜

  • 冬瓜（利水）
  • 白萝卜（消食）
  • 圆白菜（低钾）
  • 南瓜（易消化）

🍚 主食优选

  • 红薯/紫薯（粗粮）
  • 玉米（替代部分主食）
  • 荞麦面（低GI）
  • 藕粉（易消化）

🥚 优质蛋白

  • 鸡蛋（每日1个）
  • 龙利鱼（无刺）
  • 鸭血（低脂）
  • 牛奶200ml（分次饮用）

❌ 需严格控制食物

🚫 高钾食物

  • 香蕉、橙子、菠菜、土豆
  • 香菇、紫菜、海带（少量食用）

🚫 高磷食物

  • 动物内脏、坚果类
  • 加工肉类（香肠、火腿）

🚫 其他禁忌

  • 杨桃（绝对禁止）
  • 浓汤、火锅汤
  • 高盐腌制食品

📌 家庭护理要点

  • 饮水管理：每日饮水1000-1500ml（含汤水），分多次少量饮用
  • 体重监测：每日固定时间称重，24小时体重增加>1kg需警惕水肿
  • 排便观察：保持大便通畅，便秘时可少量饮用火麻仁水
  • 皮肤护理：每日用温水擦浴，避免使用碱性肥皂
  • 预防感冒：早晚温差大时及时增减衣物

🌟 紧急情况处理

  1. 出现呼吸困难、剧烈呕吐时立即就医
  2. 连续48小时无尿需急诊处理
  3. 血压持续>160/100mmHg需调整降压药
  4. 血钾>6.5mmol/L属危急值，必须立即处理
